# 17221 W. Loma Lane — House Repository of Truth

A structured record of the home at **17221 W. Loma Lane, Waddell, AZ 85355**, built from owner-provided documents. This repo is the single source of truth for the building's specifications. It is written in Markdown so it is easy for both people and AI tools to reference.

## Privacy note
This is a **public** repository. Owner contact information, signatures, third-party representative names, and financial/contract dollar figures have been **redacted**. Original source documents (which contain that information) are kept on the owner's computer and are **excluded from this repo** via `.gitignore`.
